# V115 — 사망음 종료 후 교체

이번에 첨부된 V114 / 사망 사운드(3) / 교체 등장만(2)로 제작했습니다.
ZIP 전체 압축을 해제한 뒤 index.html 또는 combat.html 실행.

아군 사망 → 사망음 재생 종료 → 다음 생존자 순환 교체 및 등장음 → 등장 연출 완료 후 전투 재개.
사망 교체는 AP 소모/자동 공격 없음. 전원 사망 시 사망음 종료 뒤 전투 종료.
공격 없는 일반 교체에도 새 등장음 적용. 공격/특수 태그의 전용음 유지.

종료 이벤트, 순환 규칙, 입력/라운드 정지, AP/피해 불변, 재개, 초기화 및 중복음 방지 테스트 통과. 실제 브라우저 청취 검수는 미실시.
